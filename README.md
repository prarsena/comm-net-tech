# Sample Code for Communications and Networking Technologies

A collection of small demos illustrating network applications, protocols, and data formats.

## Project samples

- **Chapter 3 — HTTP messaging interfaces:** [`server.py`](ch03/server.py) and
  [`tumb-server.py`](ch03/tumb-server.py) are themed, form-based HTTP demos that
  simulate message or post submissions. They do not provide encrypted messaging.
- **Chapter 5 — UDP broadcast:** [`broadcaster/`](ch05/broadcaster/) discovers
  network-interface information and demonstrates UDP broadcast with Python and
  macOS listeners. See the [chapter guide](ch05/broadcaster/README.md) for setup
  and run instructions.
- **Chapter 6 — protocols and data formats:** examples cover JSON, HTTP, DNS,
  SMTP with a local sink, and TLS certificate inspection. See the
  [chapter guide](ch06/README.md) for commands and prerequisites.

These are teaching examples; network-dependent output and required tools can vary
by platform.
